Public site of the Spartan Agentic AI Studio, served at https://agentic-spartans.github.io.

- `index.html`: landing page.
- `course/`: the eight videos and the course files download.
- `course/windows/`: the Windows guide, generated from `studio/curriculum/windows_manual/manual.md`.
- `problems/`: the example problems approved for the site, one folder each, and their index.

`course/` and `problems/` are written by `studio/release/site/build_site.py` in the Studio repository; do not edit them by hand.
