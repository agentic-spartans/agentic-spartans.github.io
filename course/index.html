Questions

Where are the slides?

One PDF per video, numbered like the videos, in the slides folder of the course repository on GitHub.

Which computer do I need?

A Mac, Windows or Linux computer you may install programs on. OpenCode has no Chromebook or iPad version.

Where should my Studio folder go?

In your home folder, the one with your name. Not in Desktop, Documents, Downloads, OneDrive or iCloud. Your course folder's name is longer than the AgentTeams in the videos; it is the same folder.

How do I install OpenCode on a Mac?

Download it from opencode.ai/download and drag OpenCode into Applications. If it will not open, click Open Anyway in System Settings › Privacy & Security.

I use Linux. How do I install OpenCode?

Download the OpenCode desktop .deb file (Ubuntu, Debian) or .rpm file (Fedora) from opencode.ai/download and double-click it to install it. A Linux walkthrough is to come.

Where do I get a key, or help?

MSU course students: in the course's D2L page. Anyone else: make an account on openrouter.ai, buy credit, then make a key and give it a spending limit. Without credit, the first run fails.

OpenCode says the port is in use?

Close its other windows and try again.
