Set up your computer

Five short steps, then your first AI team answers you. Do them once, while you watch video 2; they take about 30 minutes.

Windows: steps with picturesDownload the course files
Your computer:

You need a Mac, Windows or Linux computer you may install a program on. OpenCode, the app the course uses, has no Chromebook or iPad version.

1. Make your Studio folder

Make one folder named Studio in your home folder, the folder with your name. Do not use Desktop, Documents, Downloads, OneDrive or iCloud.

  • Mac: in Finder, press Shift-Command-H to open your home folder (it holds Desktop, Documents and Downloads). Choose File › New Folder in the menu bar and name it Studio.
  • Windows: in File Explorer, click the address bar, type %USERPROFILE% (your own folder) and press Enter. Right-click an empty spot, choose New › Folder and name it Studio.
  • Linux: open Files, click Home, and make a new folder named Studio.

2. Get the course files

  1. Download the course files. You get a zip named AgentTeams_ with a version and a date.
  2. Unzip it into Studio.
    • Mac: if Downloads shows a folder starting with AgentTeams_, drag it into Studio. If it shows only the zip, double-click the zip first.
    • Windows: right-click the zip and choose Extract All, click Browse, pick Studio, then click Extract.
    • Linux: right-click the zip, choose Extract Here, and drag the new AgentTeams_ folder into Studio.
  3. Check that Studio now holds your AgentTeams folder, with clip01, clip02, clip03, clip06 and clip08 inside.

3. Install OpenCode

  1. Go to opencode.ai/download and use the Desktop section.
  2. Install it. If it asks for an administrator password, ask the person who manages the computer.
    • Mac: open the downloaded .dmg file (an installer), drag OpenCode onto the Applications folder, and open it from Applications. When macOS asks whether to open an app from the internet, click Open.
    • Windows: click Download for Windows and open the file when it has downloaded. OpenCode opens by itself when it is installed. If a blue box says "Windows protected your PC", click More info, then Run anyway.
    • Linux: download the .deb (Ubuntu, Debian) or .rpm (Fedora) file and double-click it to install it with your software app.
  3. Check that OpenCode opens and shows a box that reads Ask anything.

4. Add your key

Your key is a secret code that lets OpenCode use the AI. MSU course students: get your key in the course's D2L page, then go to item 4 below. Anyone else: make one on openrouter.ai:

  1. Make an account and buy credit; $5 is enough for the whole course.
  2. On your account's Keys page, create a key with a credit limit of $5, so a mistake cannot cost more.
  3. Copy the key right away; it is shown only once. Treat it like a password and paste it only into OpenCode.
  4. In OpenCode, click Home (top left), then Settings below the list of projects. Click Providers, find OpenRouter and click its + Connect. In the window Connect OpenRouter, paste the key into the API key box and click Continue. OpenCode says Connected to OpenRouter.
  5. Click the model name in the message box and choose GPT-6 Luna. Check that the message box now reads OpenRouter / GPT-6 Luna.

5. Open a team and check it

  1. In OpenCode, click Home (top left), then the folder button beside Projects, and pick Studio › your AgentTeams folder › clip02 › clip02_01_simple-team.
  2. Click New session and type What agents are on this team?
  3. It works if the answer names a writer and a checker. That's it: you are set up for every video.

If something goes wrong

  • The answer names other agents: you opened the wrong folder. Open clip02_01_simple-team again and start a new session.
  • OpenCode does not open: on a Mac, open System Settings › Privacy & Security and click Open Anyway. On any computer, restart it and try again.
  • An error about the key: paste the key again (Settings, Providers, OpenRouter).
  • An error about credits: your key is out of money. Get more where you got the key.
  • OpenCode says the port is in use: close other OpenCode windows and try again.

See the hidden team files

The team's agents live in a hidden folder named .opencode.

  • Mac: in Finder, press Shift-Command-Period (.).
  • Windows: in File Explorer, click View › Show › Hidden items, and View › Show › File name extensions.
  • Linux: in Files, press Ctrl-H.
