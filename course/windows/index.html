How this guide works

The videos show a Mac; here are the same steps on Windows, each with a picture. You do not need to know anything about computers beyond turning one on, using a mouse and typing.

Each section is one thing you do in the course. Do the setup sections once, before you run a team. Do the other sections when the course gets to them. If a step does not look like the picture, go to section D1, "When something fails".

The pictures come from a Windows 11 computer; Windows 10 has not been tested yet. On Windows 10 some menus look different; where we know the Windows 10 name, the step gives it.

Steps marked Not yet tested on Windows come from the course pages and have not been tried on a Windows computer yet. Follow them, and tell us if anything differs (see Where to ask for help).

Your place is saved in this browser only. On a computer, the Left and Right arrow keys go back and next. Show the whole guide on one page to search or print it.

A0. Before you start

You need:

  • A Windows 10 or Windows 11 computer. A Chromebook, an iPad or a phone will not work. If you are not this computer's administrator, have its owner nearby for section A1: Windows may ask for their password once, when OpenCode installs.
  • This guide open in a browser on the Windows computer, beside OpenCode, so the Copy buttons work there. A phone is fine for reading along.
  • An English keyboard for typing paths and commands. If you type in another language, press the Windows key + Space to switch to English (ENG in the taskbar) first.

OpenCode is free. Only what the AI does costs money, and it comes out of your key's credit, which has a limit: a small job costs very little. The agents work only inside the team folder you open, and nothing else on the computer changes. To remove OpenCode later, uninstall it like any other app (Settings › Apps). Never give the agents private information, such as patients' or other people's details.

D1. When something fails

The team names the wrong agents, or the session shows the wrong folder

For example the answer is "This is the full team: an orchestrator coordinates five roles", or the name at the top left of the session is AgentTeams_V3_2026-11-09 instead of your team's folder name. You opened the wrong folder, such as AgentTeams or a video folder. Go to the Home page, open the team's own folder (for example clip02_01_simple-team) as in section A7, and start a new session.

A message about your key, "unauthorized" or "401"

The key was not pasted completely. Paste it again (section A6). If it still fails, ask for help (see Where to ask for help).

A message about money, "402" or "insufficient credits"

Your key has no budget left. Ask for help (see Where to ask for help).

The run stops with "This run stopped at its cost limit"

A run stops at $3. To let it go on, type /add-dollar in the same session, press Enter to pick it and Enter again to send it; it adds $1.

You want to stop a run

See section B4. Closing OpenCode does not stop a run.

Windows shows "Windows protected your PC" when the installer starts

Check that the file is opencode-desktop-win-x64.exe from opencode.ai. This is Windows' usual check for new programs. Click More info, then Run anyway.

Windows asks for an administrator password when you install

Your account is not an administrator on this computer. Ask the person who manages it (an IT help desk or the computer's owner). If you cannot, see Where to ask for help.

The Open project window says the folder does not exist

Check the path letter by letter, or copy it from File Explorer's address bar (section A7, step 4).

Word opens report.docx but stops at a sign-in or activation screen

Close Word and open report.md from the same run folder in Notepad instead (section B2 shows how). It has the same text. To use Word, sign in to Microsoft Office.

Notepad asks "Open file from an untrusted source?" when you open a course file such as README.md or task.md

The course files are safe. Click Open in Syntax View: Notepad shows the file as plain text, which is what you want for team files.

"Web search rate limited" in the agent's messages

The free web search asks the agent to slow down. Wait; the agent goes on by itself.

Words used in this guide

Folder

a place on your computer that holds files and other folders.

Home folder

your own folder on the computer, named after your Windows account, for example C:\Users\yourname.

Path

the address of a file or folder, for example C:\Users\yourname\Studio.

Zip file

one file that packs many files and folders together. Extract means unpacking it into normal folders.

File extension

the letters after the last dot in a file name, such as .md, .json or .txt. They tell Windows what kind of file it is.

Hidden file or folder

a file Windows does not show unless you turn on "Hidden items". Its name often starts with a dot, like .opencode.

Key

a secret code that lets OpenCode use the AI and pays for what it uses.

Session

one conversation with the agents in OpenCode.

Run

one job the team does after you type /do. Each run gets its own folder, runs\run_1, runs\run_2 and so on.

Token

a small piece of text, about three quarters of a word. AI services count and charge by tokens.

Model

the AI that does the thinking; the course uses GPT-6 Luna.

clip01, clip02, …

the course download has one folder per video that has a team; clip02 goes with video 2.

Provider

the service that connects OpenCode to the model; the course uses OpenRouter.

Markdown

plain text with a few marks for headings and lists; files that end in .md.

Subagent or helper

an agent that another agent starts for one task, such as the Checker.

Agent

an AI with a role, instructions and tools. A team is several agents that pass work to each other.
